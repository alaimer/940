# 940 — Web Deployment Repository

هذا المستودع مخصص لنشر النسخة المبنية من **940 Web** فقط. التطوير والكود المصدري وإدارة الإصدارات تتم في المستودع الخاص بالمشروع. لا يُستخدم هذا المستودع للتطوير أو لإجراء تعديلات مباشرة على 940.

This repository is for deploying the built **940 Web** output only. Development, source code and release management happen in the project's private repository. Do not use this repository for development or direct edits to 940.

- الموقع / Site: https://alaimer.github.io/940/
- الإصدار / Version: 1.13.2
- المصدر الحقيقي / Source of truth: المستودع الخاص بالمشروع (غير منشور)
- قاعدة التحديث: أي تعديل يتم أولًا في المستودع الخاص، ثم يُختبر ويُعتمد، ثم تُبنى مخرجات 940 Web وتُنسخ إلى هنا.
- ممنوع تعديل الملفات هنا مباشرة؛ أي تعديل مباشر سيُستبدل عند النشر التالي.
